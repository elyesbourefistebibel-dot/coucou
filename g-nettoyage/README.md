# G-Nettoyage

Site vitrine de G-Nettoyage, entreprise de nettoyage professionnel.

Site statique (HTML, CSS, JavaScript), sans dépendance ni étape de build : ouvrez `index.html` dans un navigateur.

## À personnaliser

- Téléphone, e-mail, zone d'intervention et horaires : section « Contact » de `index.html`
- Adresse qui reçoit les demandes de devis : `CONTACT_EMAIL` en haut de `script.js`
- Couleurs de la charte (vert sapin `#0f3d33`, citron vert `#c4e45a`, blanc cassé `#fbfaf5`) : variables en haut de `styles.css`
- Logo : symbole `logo-mark` en haut de `index.html` et fichiers dans `assets/`

## Mise en ligne

Le dossier peut être publié tel quel sur GitHub Pages, Netlify, Vercel ou tout hébergeur statique.
